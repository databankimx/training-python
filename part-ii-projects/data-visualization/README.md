## Data Visualization

This chapter group covers Ch15-17 of *Python Crash Course*. The two editions of the
book handle data visualization differently, so each edition is kept separately:

* **`2nd-edition/`** - Ch15-17 as laid out in the 2nd edition (matplotlib, and the
  2nd edition's versions of the data and API examples)
* **`3rd-edition/`** - Ch15-17 as laid out in the 3rd edition (pyplot, plotly, and the
  3rd edition's data and API examples)

Each edition has the same structure:

* `ch15-generating-data/`, `ch16-downloading-data/`, `ch17-working-with-apis/`
* Each chapter contains `lessons/`, `try-it-yourself/`, and `textbook-downloads/`

Follow the edition that matches your copy of the book. The 3rd edition is the one this
training is based on, and the 2nd edition is kept for reference, as the root README
explains.
