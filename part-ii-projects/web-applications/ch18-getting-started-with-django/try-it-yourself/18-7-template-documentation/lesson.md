# Exercise 18-7: Template Documentation

## The exercise

Skim the Django template documentation at https://docs.djangoproject.com/en/5.2/ref/templates/. You can refer back to it when you're
working on your own projects.

## Running this exercise

This is a reading exercise. There's no code to run.

1. Open the documentation page above.
2. Skim the headings, and look for the tags and filters you've used so far: `{% extends %}`, `{% block %}`, `{% for %}`, `{% empty %}`,
   `{% url %}`, `{{ value|date }}` and `{{ value|linebreaks }}`.
3. Choose one tag or filter that you haven't used yet, and read its entry. Write down what it does in one sentence.

## What to look for

- **Tags** use `{% %}` and control the page, such as loops and blocks.
- **Variables** use `{{ }}` and show a value.
- **Filters** change a value on the way out, such as `date` and `linebreaks`. They follow a `|` after the value.

## Solution

There's no code to submit. Your check is one sentence for the tag or filter you chose, in your own words.

## Output

None. This exercise doesn't produce a page.
