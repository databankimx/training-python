# Chapter 12: Try It Yourself

These exercises build on the chapter's ideas with small programs of their own. Each exercise is
in its own folder, and runs by itself, separate from the Alien Invasion steps.

| Folder | Exercise |
|---|---|
| `12-1-blue-sky` | 12-1: a Pygame window with a blue background |
| `12-2-game-character` | 12-2: draw a game character at the center of the screen |
| `12-4-rocket` | 12-4: a rocket the player moves with the four arrow keys |
| `12-5-keys` | 12-5: print the key code of each key press |
| `12-6-sideways-shooter` | 12-6: a ship on the left that moves up and down and fires missiles right |

To run an exercise, open a terminal in its folder, and run its program with `python`. Each
exercise's lesson page gives the file to run.

## Exercise 12-3: Pygame Documentation

This exercise has no code. Skim the Pygame documentation at https://www.pygame.org/docs/. You
won't need it for these exercises, but it will help if you want to change Alien Invasion or make
a game of your own.

## Images

The rocket image, `rocket.bmp`, is used by exercises 12-2, 12-4 and 12-6. Each of those folders
has its own `images` folder with a copy of the file.
