### Option 2: Minimal Setup

#### Install a Code Editor

VS Code is recommended for Python training, but any editor will work.

* Download [Visual Studio Code](https://code.visualstudio.com/) and install manually, or
* Install using WinGet: `winget install Microsoft.VisualStudioCode`

---

I wrote these lessons on Windows. If you're on macOS or Linux, Appendix A of the book walks you through the install. Python itself behaves the same everywhere, so the rest of the lessons still apply.

#### Install Python

* Download [Python](https://www.python.org/downloads/) and install manually, or
* Install using WinGet: `winget install Python.Python.3.12`

Python 3.12 or later is required for these lessons and the book's exercises.

---

#### Test Your Installation

From a command prompt:

1. Run `python --version` - should show your version, e.g. `Python 3.12.0`
2. Run `python` - should show the Python prompt: `>>>`
3. Type `print("Hello")` and press Enter - should show `Hello`
4. Type `exit()` and press Enter to return to your normal prompt
