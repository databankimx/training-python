## Adding Items to a List

You can add a new item to the end of a list using the `append()` method.

```python
motorcycles = ["honda", "yamaha", "suzuki"]
print(motorcycles)
motorcycles.append("triumph")
print(motorcycles)
```

Output:

```
['honda', 'yamaha', 'suzuki']
['honda', 'yamaha', 'suzuki', 'triumph']
```
