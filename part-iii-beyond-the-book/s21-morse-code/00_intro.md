## Morse Code

Morse code represents each letter, digit, and punctuation mark as a series of
short signals (dots) and long signals (dashes). This lesson builds an encoder
and decoder that use a binary tree to translate between text and Morse code.

The code is in this folder:

* [`main.py`](./main.py) - an interactive program, plus a demo
* [`morse.py`](./morse.py) - the encoder and decoder
* [`node.py`](./node.py) - a node in the tree

The lesson on the tree is here:

* [Morse Code as a Binary Tree](./01_morse_tree.md)

---

### Running the Program

Run the interactive program:

```pwsh
python main.py
```

Choose `e` to encode a message, `d` to decode one, or `q` to quit. Run the
demo to see a set of fixed examples:

```pwsh
python main.py demo
```
